위험구역 작업자 추적 관제실

물체 하나를 작업자로 가정하고, 관제소의 지시·현장의 자동 경고·목적지 문 개방을 서로 구분해 구현한다. STM32는 측정과 제어, ESP32는 e-Ink 화면을 담당한다.

01 / REQUIREMENTS

프로젝트 흐름

대화에서 확정한 내용
01
출발 전 지도 확인관제소 e-Ink에서 경로와 빨간 위험구역을 확인한다.
02
작업자 역할의 물체 이동직선·직각으로 구성된 복도 4구간을 물체 하나가 이동한다.
03
위치 추정과 지도 표시복도별 초음파 → STM32 좌표 추정 → ESP32 → 흰색 위치점.
04
관제소의 상태 지시PC에서 보낸 UART 명령에 따라 작업자용 LED 2개를 변경한다.
05
매우 위험한 지점 경보별도 초음파 S5가 접근을 감지하면 부저 ON, 이탈하면 OFF.
06
목적지 문 개방관제자가 ARRIVED 전송 후 키패드 숫자 0 입력 → 서보모터로 문 한 개 개방.

요구사항 근거: 사용자 최종 합의와 「01_2조_프로젝트_주제신청서_역할추가.docx」. 03~05는 순서대로 한 번만 실행하는 절차가 아니라 이동 중 병행되는 기능이다. [L1]

관제소의 역할

지도에서 작업자의 위치와 위험구역을 확인하고, 하이퍼터미널로 현장에 양호·경계·위험·도착 지시를 보낸다. PC는 관제 명령 입력 장치이며, e-Ink는 위치 현황판이다.

작업자와 현장의 역할

작업자는 출발 전에 지도를 보고, 이동 중에는 LED 2개로 지시를 확인한다. 실제 사람 대신 물체 1개를 사용한다. LED·PIEZO는 기존 키트에 두어도 되며, 목적지 문은 모형 한 곳만 움직인다.

02 / ARCHITECTURE

장비와 데이터는 이렇게 연결한다

구현된 통합 구조

STM32에 붙는 것

초음파 5개, 기존 키패드, 기존 LED 2개, 기존 PIEZO, 외장 SG90 1개. 하이퍼터미널과 ESP32는 서로 다른 UART를 사용한다.

ESP32에 붙는 것

DESPI-C02의 SPI·제어 신호와 STM32 통신선. 화면용 SPI는 STM32가 아니라 ESP32에서 출력한다. Wi-Fi는 MVP에 필요하지 않다.

브레드보드 1개의 역할

주로 초음파센서 전원·GND 분배와 연결 시험에 사용한다. 센서의 TRIG/ECHO는 보유 케이블로 MCU에 직접 연결할 수 있다. 모터의 큰 전류를 반드시 이 보드로 흘리는 구조는 아니다.

PC에 연결하는 USB 두 종류를 구분한다.

STM32 MCU 모듈의 USB는 기존 DFU 다운로드에 사용한다. 하이퍼터미널은 키트 UART 모듈의 USB-to-Serial 포트에 연결한다. 교수님 제공 ESP32의 USB는 ESP32의 펌웨어 다운로드·전원용이며, STM32와의 실제 데이터선은 별도 UART 두 선이다.

수업자료: 「01_GPIO_Output.pptx」의 IAR/DFU 절차, 「실험5-UART-with 과제.pdf」13~17쪽. 공식 DESPI-C02는 SPI 어댑터이며 3.3V로 동작한다. [L2][W2]

04 / STM32 PIN MAP

STM32 실제 연결 계획

구현 핀 배정

핀 이름은 MCU 모듈에 표시된 PAx·PBx·PCx 신호명이다. 칩의 물리적인 다리 번호나 헤더의 몇 번째 구멍이라는 뜻이 아니다. 포트의 인쇄 표기와 케이블 방향을 대조해 연결한다.

전원 확인 전 센서 ECHO를 연결하지 않는다.

이 안은 HC-SR04P를 3.3V로 공급하고 ECHO가 3.3V 수준임을 실측하는 조건이다. 특히 복도 ECHO에 쓰는 PA0~PA3은 ST 표에서 5V-tolerant(FT) 핀으로 표시되어 있지 않다. 센서를 5V로 구동하거나 다른 HC-SR04로 교체하면 입력 전압을 다시 검토하고 필요한 레벨 변환 후 연결한다.

PA0~PA3, PA6, PA8, PB6 및 USART 핀 기능은 ST 데이터시트 Table 5와 실습 핀 표를 대조했다. 실제 센서 출력 전압은 제품명만으로 보증하지 않는다. [W3][W5][L2]

초음파 센서 5개의 접지와 전원

STM32 J5 4번(GND) → 브레드보드 − 레일 → 센서 5개의 GND. 센서용 정전압 3.3 V 전원의 음극도 같은 레일에 연결한다. 5개를 공급할 수 있는 전원의 양극을 + 레일에 연결하고, 다섯 VCC를 그 레일에 연결한다. 별도 전원의 양극은 J5 1·2번과 분리한다.

전원을 끄고 JTAG 헤더가 비었는지 확인한다. 왼쪽 GPIO 소켓과 MCU 칩 사이에 있는 검은 2×10 헤더가 J5다. 기판의 1번 맞은편이 2번이고, 2번과 같은 열의 바로 다음 핀이 4번이다. 브레드보드 레일은 사용할 구멍끼리 도통을 확인한다.

빨간 RESET 버튼을 오른쪽 아래에 두면 TRIG 5개는 오른쪽 J4의 왼쪽 열(2-L)에 있다. ECHO는 S1~S4가 왼쪽 J3의 왼쪽 열(1-L), S5가 J3의 오른쪽 열(1-R)이다. S1은 PC8에서 TRIG로, ECHO에서 PA0으로 연결한다. 실험1-GPIO-InputOutput.pdf 20쪽 소켓 사진·21쪽 회로도

키트 UART 표기 주의

실습자료는 PA9 → UART 모듈 TX0, PA10 → RX0로 명시한다. 이 키트의 표기를 일반 외부 모듈의 TX/RX 표기와 혼동해 임의로 뒤집지 않는다. 실제 신호는 ‘STM32 TX → 변환기 입력’, ‘변환기 출력 → STM32 RX’가 되어야 한다.

[L2: UART 자료 15쪽]

서보·부저·LED가 충돌하지 않게

서보는 PA8 / TIM1, 부저는 PA6 / TIM3, LED는 PA4·PA5로 분리한다. 예전 LED 실습처럼 PA0~PA7 전체를 덮어쓰거나 출력으로 초기화하면 초음파 입력과 부저 핀까지 손상된 설정이 되므로 해당 코드 그대로 사용하지 않는다.

쓰지 않는 핀과 재할당(remap) 제한

사용 금지 범위: 수업자료에서 USB·디버그·오실레이터 등으로 예약한 PA11~PA15, PB3~PB4, PC14~PC15, PD0~PD2는 건드리지 않는다. PB2도 부팅 설정과 관련 있으므로 이 안에서는 비운다.

기본 매핑 유지: USART1은 PA9/PA10, USART3는 PB10/PB11, TIM1/2/3/4는 기본 핀 배정이다. USART3를 PC10/PC11로 remap하면 S3·S4 TRIG와 충돌한다. TIM3를 PC6~PC9로 remap하면 키패드·TRIG와 충돌한다.

예약하지 않은 여유 핀: PA7, PB0·PB1·PB5·PB7~PB9·PB12~PB15, PC7 등은 확장용으로 남긴다. 여유 핀의 실제 사용도 보드 회로와 대조해야 한다.

72MHz 타이머 클록을 기준으로 한 PSC 예시다. 펌웨어는 SPL RCC_GetClocksFreq로 읽은 HCLK·PCLK와 APB 배율로 분주값을 계산한다. TIM1 PWM은 보정된 두 펄스 폭이 있을 때만 MOE를 활성화한다. t_ms는 STM32 기동 후 경과 밀리초이며, 센서 슬롯·점멸·화면 지연은 실물에서 측정한다.

[W3: clock tree, Table 5][L4: System_func.c / TIM 라이브러리]

PC → STM32 관제 명령

구현된 입력 수업 설정과 같은 9600bps / 8N1 / 흐름제어 없음이다. 대문자 ASCII 명령을 한 줄씩 보낸다.

SAFE\r\n       → 양호
CAUTION\r\n    → 경계
DANGER\r\n     → 위험
ARRIVED\r\n    → 도착 허가
RAW\r\n        → R,S1,S2,S3,S4,S5

네 관제 명령은 OK로 응답한다. RAW는 다섯 센서의 마지막 거리(mm)를 돌려준다. 미측정·무효 ECHO는 -1이다. CR, LF, CRLF를 처리한다. 잘못된 명령은 ERR COMMAND, 현재 LED 상태는 유지한다. 점멸은 500ms 켜짐 / 500ms 꺼짐이다.

STM32 ↔ ESP32 위치·상태

구현된 프레임 115200bps / 8N1로 위치와 관제·경보·문 상태를 전송한다.

P,seq,t_ms,corridor,x_mm,y_mm,valid\r\n
S,command,alarm,door\r\n
// ESP32 → STM32: READY 또는 ERROR

P의 구간은 1~4이며, 위치 미확인은 구간·좌표·valid를 모두 0으로 보낸다. S의 command는 NONE/SAFE/CAUTION/DANGER/ARRIVED, alarm은 UNKNOWN/CLEAR/ACTIVE/FAULT/ACTIVE_FAULT, door는 UNSET/CLOSED/OPEN이다. ESP32는 입력을 검증하고 최신값을 보관한다. STM32는 READY 응답을 기다리지 않고 측정·전송한다.

입력 캡처와 timeout 구현 주의

TIM2/4는 센서마다 정지·초기화하지 않는 free-running counter로 사용한다. 각 채널에서 상승 에지 시각을 기록하고 하강 에지로 전환해 펄스 폭을 구하는 방식을 사용한다. 이 안은 센서마다 채널 두 개를 쓰는 PWM-input reset mode가 아니라 채널 하나에서 극성을 전환하는 입력 캡처이다.

1MHz·16비트 카운터는 65.536ms마다 순환하므로, 한 번의 순환 이내에서 dt_us = (uint16_t)(fall - rise)로 계산하고 그보다 짧은 timeout을 둔다. Echo 없음·High 고착·범위 밖은 거리 0이 아니라 INVALID로 처리한다. timeout 후 해당 측정을 정리하고 다음 슬롯으로 진행한다.

ISR에서는 캡처값 저장과 이벤트 표시만 하고, 로그 출력·e-Ink 갱신·오래 걸리는 계산은 하지 않는다. 기존 타이머 delay 예제가 TIM2/3을 끄는 부분은 통합 코드에 그대로 가져오지 않는다.

센서 순차 측정과 초기 타이밍
S5 → S1 → S5 → S2 → S5 → S3 → S5 → S4 → 반복

센서가 서로의 초음파를 받지 않도록 한 번에 하나만 송신한다. 슬롯을 60ms로 설정하면 위험지점은 약 120ms마다, 각 복도는 약 480ms마다 갱신된다. 이 값은 HC-SR04P의 보장 사양이 아니라 잔향·간섭 시험을 시작하기 위한 제안값이다. Echo timeout 30ms와 TRIG 약 10μs 역시 수령품 동작을 확인해 확정한다.

이 경우 감지·부저 반응에는 센서 대기와 필터 지연이 있고 e-Ink에는 별도 갱신 지연이 더해진다. 따라서 ‘지연 0’이나 ‘1ms 경고’를 보장하지 않는다.

다중 초음파 상호 간섭과 순차 구동의 일반 원리는 제조사 자료를 참고했다. MaxBotix의 제품별 핀·타이밍을 HC-SR04P에 그대로 적용한 것은 아니다. [W7]

08 / CONTROL LOGIC

좌표 추정·위험 경보·문 제어

구현된 동작

1. 초음파 거리에서 복도 위 좌표로

이 프로젝트는 임의 공간의 사람 위치를 자유롭게 찾는 시스템이 아니라, 알려진 직선 통로를 따라 움직이는 물체 1개의 위치를 추정하는 시스템이다. 각 복도의 시작점, 길이, 방향, 센서 설치점과 offset을 먼저 측정해 저장한다.

거리 근사: d_mm ≈ 343 × Echo_시간(μs) / 2000   // 음속 343m/s를 사용한 계산 예
좌표:      p = p_sensor + (d_mm + offset) × u_corridor
화면: 각 복도의 보정 거리 비율을 모식도 해당 구간의 길이에 대응
           S1·S3 수평 / S2·S4 수직, +x 오른쪽, +y 아래쪽

음속 고정값은 초기 근사이며 온도·실물 보정이 필요하다. 초음파가 측정하는 것은 물체의 반사면까지 거리이므로, 점이 물체 중심을 뜻하려면 일정한 표적 형상과 방향 또는 별도의 보정이 필요하다. 화면 y축 방향도 좌표계 변환에 포함한다.

어느 복도에 있는지

빈 복도에서 읽는 배경 거리를 저장한다. 새 측정이 빈 복도보다 설정 여유 이상 가깝고 통로 길이 안에 있을 때 후보로 잡는다. 이전 복도·인접 복도 관계, 이동량, 측정 시각으로 후보를 선택한다.

5개 값 중 가장 짧은 거리를 고르는 방식은 쓰지 않는다. S5는 위치 후보 선정이 아니라 별도의 위험 접근 감지에 사용한다.

코너와 가림 구간

90도 모서리에서는 두 센서에 보이거나 어느 센서에도 안 보일 수 있다. 모형은 물체가 센서 시선 밖으로 크게 벗어나지 않게 만들고, 중복·무검출 구간을 실제로 측정한다.

확신이 없으면 마지막 위치를 ‘현재 위치’처럼 유지하지 않고 위치 미확인 / 마지막 측정 경과시간을 표시한다. 신뢰성은 통로 단품 시험을 통과한 뒤 판단한다.

2. S5 위험 접근 경보

접근 기준 D_on, 해제 기준 D_off를 구분하고 D_off > D_on으로 둔다. 설정된 연속 횟수만큼 접근이나 이탈을 검출하면 부저를 켜거나 끈다. 거리·필터 수치는 모형에서 정하며 임의의 확정값으로 넣지 않는다.

S5가 응답하지 않으면 오류를 보고한다.

실측 보정 전 경보 상태는 UNKNOWN이다. 보정 후 측정 오류는 FAULT이며 이미 울리던 중에는 ACTIVE_FAULT로 전송하고 부저음을 유지한다. 이 장치는 교육용 모형이다.

3. 목적지 문 하나 열기

확정: 도착 후 키패드 숫자 0을 누르면 SG90으로 문을 연다. 별도 스위치 모듈의 BT0가 아니다. 키패드는 디바운싱 후 ‘눌림 에지’ 한 번만 처리하고 길게 눌렀다고 모터 동작을 반복하지 않는다.

항목현재 동작
모터SG90 1개. 문은 별도 경첩이 지지하고 혼과 연결부가 힘을 전달한다.
보정무부하 시험으로 닫힘·열림 펄스 폭을 site_profile.h에 입력한다. 미보정은 UNSET이며 PA8에는 서보 펄스를 출력하지 않는다.
도착과 개방관제자가 ARRIVED를 보낸 상태에서 디바운싱된 새 숫자 0 입력을 받으면 한 번 연다. 슬라이더 위치나 자동 좌표는 개방 허가 조건에 쓰지 않는다.
다시 시연문은 열린 상태를 유지한다. 보정된 상태에서 보드를 리셋하면 닫힘 목표로 시작한다. OPEN/CLOSED는 펌웨어가 명령한 목표다.
09 / DISPLAY IMPLEMENTATION

전자종이 펌웨어와 화면 갱신

표시 속도·잔상은 실물 검증

제조사 드라이버와 프로젝트 코드

esp32/build.ps1은 Good Display 공식 ESP32epdx의 고정 커밋에서 GDEY075Z08 전용 EPD.cpp·SPI·GUI를 가져온다. ControlRoom.ino는 UART 수신과 화면 상태를 관리하고, panel.cpp가 지도·빨간 표지·위치점을 그린다.

[L3: 실제 빌드에 사용한 제조사 예제]

갱신 특성

공식 GDEY075Z08 사양은 25℃에서 전체 약 18초, 빠른 갱신 약 12초, 흑백 부분 갱신 약 1.5초다. 현재 펌웨어는 일반 전체 갱신과 흑백 부분 갱신을 사용한다. 첫 표시 시간·잔상·적색 유지 여부는 실제 패널에서 기록한다.

[W1]

화면 구성 원칙

검은색 지도·벽, 흰색 위치점과 검은 외곽선, 빨간 위험구역 경계·표지를 유지한다. 점을 지울 때는 무조건 흰색으로 지우지 않고 이전 위치 영역의 원래 지도 배경을 복원한다. 변경된 바이트에서 부분 갱신 창을 계산한다. 창에 빨간 화소가 포함되면 전체 갱신한다.

빨간 화소를 자주 바꾸지 않도록 위험구역은 경계·표지로 표시하고 위치점의 갱신 영역과 겹치지 않게 한다. 다만 부분 갱신에서 빨간 화소가 안정적으로 유지되는지는 실제 패널에서 확인해야 한다. ‘항상 표시’는 정상 표시 화면마다 위험구역이 포함된다는 의미이며 전체 갱신 도중의 깜빡임까지 없다는 보장은 아니다.

메모리와 화면 대기

800×480 한 평면은 48,000바이트다. ESP32에 흑백·빨강·부분 갱신 기준 버퍼를 각각 하나씩, 합계 144,000바이트를 할당한다. 부분창 전송 임시 버퍼는 변경 영역 크기만큼 추가된다. STM32는 위치·상태 프레임만 전송한다.

BUSY가 30초 동안 해제되지 않으면 갱신을 중지하고 ERROR를 보낸 뒤 전체 갱신으로 재시도한다. 화면이 구동되는 동안 UART 수신 태스크는 최신 위치와 상태를 별도로 보관한다.

화면에는 마지막으로 완료된 갱신 결과가 보인다.

변경 창이 누계 다섯 회를 넘게 되면 전체 갱신한다. 위치·상태 프레임 각각 약 2.5초 동안 새 수신이 없으면 미확인으로 전환한다. 마지막 유효 위치가 있으면 수신 경과시간의 하한을 10초 단위로 표시한다. 화면 자체의 갱신 시간만큼 표시가 늦어질 수 있다.

10 / BUILD & VERIFY

완성 순서와 통과 기준

단품 검증 → 통합
소프트웨어에서 확인한 결과

STM32는 IAR EMB_FLASH 빌드와 벡터 주소 0x08003000을 확인했다. ESP32는 Arduino-ESP32 2.0.17로 빌드했다. PC에서 STM32가 생성한 정상 프레임 7개를 실제 ESP32 파서로 읽고, 화면 코드로 이전 점 복원·빨강 보존·BUSY 타임아웃 복구를 검증했다. 아래 절차는 실제 보드와 모형에서 진행한다.

GATE 0 / 실제 부품 식별

모델·전원·배선 확인

사진으로 확인한 ESP32-L·DESPI-C02 표기와 실물을 대조한다. 패널 모델 라벨, 키트 3.3V/5V 출력 단자·전류, 케이블 방향 확인. 확정된 핀 표로 라벨링한다.

통과 기준: 전압·접지·핀 대응을 설명하고 측정 기록을 남길 수 있음.
GATE 1 / 디스플레이

기존 예제 → 지도 → 점

제공 예제 구동, 지도와 빨간 표지 표시, 점 이동·지우기, 부분 갱신 횟수 및 전체 갱신 검증.

통과 기준: 색상·잔상·갱신 시간을 실물로 확인. 위치 표시가 실제 시간보다 얼마나 늦는지 기록.
GATE 2 / 초음파

한 통로 → 4구간 + S5

PC에서 RAW로 평평한 표적과 빈 통로의 거리값을 수집하고, 벽 반사·코너 누락·다중 간섭을 확인한다.

통과 기준: 구간별 오차와 미검출 구간을 기록하고, 모형 크기·배치를 결정.
GATE 3 / 독립 제어

관제 LED와 자동 부저

4개 명령의 LED 패턴, S5 접근·이탈, 잘못된 UART 입력, Echo timeout을 시험한다.

통과 기준: LED 명령과 부저 조건이 서로를 잘못 덮어쓰지 않음.
GATE 4 / 문 개방

키패드 0 → PWM → 문

서보 무부하 시험, 기존 키트 5V 유지 상태 확인, 문 링크 조정, ARRIVED·새 숫자 0 입력·리셋 시 닫힘 목표 확인.

통과 기준: 0을 한 번 눌렀을 때 한 번 열리고, 기구 걸림과 MCU 리셋이 없음.
GATE 5 / 통합 시연

화면 갱신 중에도 동작

전체 갱신 중 관제 명령·S5 접근·키패드 입력을 넣어 본다. ESP32 재시작·선 분리도 시험한다.

통과 기준: STM32 측정·LED·경보가 화면 대기에 막히지 않음. 모든 오류·지연을 구분해 설명 가능.
