# 서보 회전식 초음파 탐지기

SG90의 회전축에 HC-SR04P 센서 한 개를 고정한다. STM32F103RBT6가 서보를 좌우로 움직이고 각 위치에서 거리를 잰다. 물체가 감지 범위에 들어오면 STM32가 피에조를 울리고 감지 각도와 거리를 UART로 보낸다. ESP32-L은 이 데이터를 받아 7.5인치 흑백 전자종이에 표시한다.

| 파일 | 용도 |
|---|---|
| [배선도 PDF](docs/wiring.pdf) | 1쪽은 센서·서보·피에조·전원, 2쪽은 ESP32-L과 패널 커넥터 |
| [STM32 IAR 워크스페이스](stm32/SweepScan.eww) | 메인 제어 펌웨어. 기존 실습의 STM32F10x Firmware Library V1.0과 부트로더용 벡터 위치를 사용 |
| [ESP32 준비 스크립트](esp32/build.ps1) | Good Display 흑백 드라이버와 이 프로젝트의 화면 코드를 조합해 Arduino IDE에서 열 스케치를 생성 |

## 조립과 전원

1. 서보 몸체를 바닥에 고정한다. 센서 고정용 혼을 분리하고 `stm32/scan_config.h`의 `CENTER_ONLY`를 `1`로 바꿔 아래 절차로 빌드·업로드한다. 서보가 90° 중앙에 멈추면 전원을 끄고, 축이 돌아가지 않게 센서가 정면을 향하도록 혼과 브래킷을 고정한다. 이후 `CENTER_ONLY=0`으로 되돌려 빌드·업로드하면 왕복 스캔이 시작된다.
2. 센서의 둥근 송신부·수신부 앞을 비운다. 센서 전선 네 가닥이 회전 끝에서 당겨지지 않게 여유를 준다. 센서와 서보는 기계적으로 결합하고, 두 장치의 신호선은 각각 STM32로 연결한다.
3. HC-SR04P는 3.3 V 동작형을 사용한다. ECHO의 HIGH가 3.3 V 범위인지 확인한 뒤 PA0에 연결한다. 같은 모양의 5 V ECHO 제품으로 교체하면 레벨 변환이 필요하다.
4. SG90의 전원은 실물 제품 정격과 구동 전류를 충족하는 별도 전원으로 공급한다. PA8은 제어 신호다. 센서·서보·ESP32-L·STM32는 GND를 공유한다. 서보 전원 양극을 키트나 ESP32의 3.3 V에 연결하지 않는다.

| STM32 단자 | 연결 대상 | 역할 |
|---|---|---|
| PC8 | HC-SR04P TRIG | 측정 시작 펄스 출력 |
| PA0 | HC-SR04P ECHO | 반사 펄스 시간 측정, TIM2_CH1 |
| PA8 | SG90 Signal | 서보 위치 PWM, TIM1_CH1 |
| PA6 | 키트 PIEZO 입력 | 감지음 PWM, TIM3_CH1 |
| PB10 | ESP32-L P6-9, SDA/GPIO21 | USART3 TX → ESP32 UART2 RX, 115200 8N1 |
| GND | ESP32-L P6-7, 센서 GND, 서보 및 전원 GND | 공통 기준 전위 |

## 소프트웨어 설치

**STM32** · ZIP 전체를 압축 해제한다. IAR EWARM에서 `stm32/SweepScan.eww`를 열고 `EMB_FLASH`를 선택한 뒤 Make(F7)한다. `stm32/EMB_FLASH/Exe/SweepScan.hex`를 DFU File Manager의 `S19 or Hex...`로 불러와 `Generate`로 DFU를 만든다. MCU 모듈의 USB를 PC에 연결하고 PROG를 누른 채 MCU 전원을 켠다. DfuSe Demo에서 해당 키트를 선택하고 `Choose → Upgrade`를 실행한 뒤 RESET을 누른다. 이 프로젝트의 앱 시작 주소는 `0x08003000`이다.

**ESP32** · Windows의 Arduino IDE 보드 관리자에서 `esp32 by Espressif Systems` **3.3.12**를 설치한다. 패키지 검색이 안 될 경우 IDE 환경설정의 추가 보드 관리자 URL에 `https://espressif.github.io/arduino-esp32/package_esp32_index.json`을 추가한다. 이 README가 있는 폴더에서 PowerShell로 다음 명령을 실행한다. 처음 한 번 제조사 드라이버를 받을 인터넷 연결이 필요하다.

```powershell
.\esp32\build.ps1 -PrepareIde
```

출력된 경로의 스케치를 열고 보드 **ESP32 Dev Module**, 포트 **ESP32-L을 켤 때 나타나는 CH340**을 선택해 업로드한다. 패널은 **Seeed T075A04, 800×480, 흑백**이다. ESP32-L의 큰 기판 P3에 패널 전원 점퍼를 꽂고 DESPI-C02의 작은 P3 스위치는 **0.47 Ω**로 둔다. [이전 프로젝트에서 동일 패널을 구동한 기록](https://github.com/tokengeoji/mcu/blob/aabd01030d0038dad720c88001f49b633c6ae5fd/docs/epaper-monochrome-fix.md)

## 첫 동작 확인

| 관찰할 동작 | 확인 방법 |
|---|---|
| 좌우 왕복 | 센서를 정면에 맞추고 전원을 켠다. 기본 서보 명령은 정면 90°에서 시작해 60~120°를 5° 단위로 왕복한다. 실제 축 각도는 혼 장착 위치와 서보 개체에 따라 달라진다. |
| 거리와 부저 | 평평한 물체를 정면 약 20 cm에 놓고 센서가 그 방향을 볼 때 부저가 울리는지 확인한다. 기본 감지 기준은 30 cm 이내이고 해제 기준은 35 cm다. 물체가 같은 위치에 있어도 센서가 다른 쪽을 보고 유효한 근접 반사가 사라지면 소리가 멎을 수 있다. |
| 전자종이 | 스캔 중 물체를 한 차례 감지시킨 뒤 화면의 감지 각도와 거리를 확인한다. 첫 패널 구동과 화면 갱신에는 시간이 걸린다. 부저가 화면보다 먼저 반응하는 것이 정상이다. |
| 화면만 반응하지 않을 때 | 모터와 부저가 반응하면 표시 쪽부터 확인한다. PB10 → P6-9, 공통 GND → P6-7, 패널 전원 점퍼, 리본 방향과 잠금, DESPI-C02의 0.47 Ω 설정 순서로 본다. |

기본 UART 한 줄은 `SCAN,순번,감지여부,서보명령각도,거리mm`와 CRLF다. 예를 들어 `SCAN,42,1,90,215`는 42번 측정에서 정면 90°에 215 mm로 감지했다는 뜻이다. 거리 `-1`은 유효한 반사를 얻지 못했다는 뜻이다. 각도는 서보에 명령한 값이며 거리만 센서 실측값이다.

## 바꿀 수 있는 기본값

모터와 감지 설정은 [scan_config.h](stm32/scan_config.h)에 모아 두었다. 정상 모드는 전원을 켠 뒤 3초간 중앙에 머물고, 각 위치로 이동한 후 80 ms를 기다려 측정한다. 같은 초음파 펄스의 왕복 시간을 mm로 환산한다.

| 변경할 동작 | STM32 설정 이름 | 기본값 |
|---|---|---|
| 스캔 범위와 간격 | `SCAN_LEFT_DEG`, `SCAN_RIGHT_DEG`, `SCAN_STEP_DEG` | 60°, 120°, 5° |
| 이동 후 센서가 안정될 시간 | `STEP_SETTLE_MS` | 80 ms |
| 감지·해제 거리 | `ALERT_ENTER_MM`, `ALERT_RELEASE_MM` | 300 mm 이하에서 감지, 350 mm 이상 또는 무효 측정에서 해제 |
| 피에조 음높이 | `BUZZER_HZ` | 약 1,024 Hz |

프로젝트 파일의 상대 경로와 STM32 C 소스의 Cortex-M3 대상 구문·타입을 확인했다. IAR 최종 링크, ESP32 보드 패키지 빌드, 실물의 모터·센서·부저·화면 통합 시운전은 미확인이다. 이전 펌웨어의 고정 지도 실물 성공 기록은 위 패널 모델 선택의 근거다.
